## A chat from Markdown

> Use a chat fence when the scene needs no scene.ts: one message per line, "user: " on the right, "Name: " for a colleague, no prefix for the assistant. Each message is one step; the list items after the fence are the steps' text.

```chat
user: Can the build run on my laptop?
Yes. Run npm ci once, then npm test.
Ana: I can pair with you on it after lunch.
```

- The question.
- The assistant answers.
- A colleague offers help.

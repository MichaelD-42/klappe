## One deck, two languages

> The deck is written in English (deck.md lang: en); lang/de.md holds its German text, each scene.md line and each ctx.t() string quoted, with the translation under it. `npm run lang -- de` writes and updates that file, and a walk with --lang de names what is still missing. Press S and pick Deutsch, or open the deck with ?lang=de.

- A string in scene.ts goes through ctx.t().

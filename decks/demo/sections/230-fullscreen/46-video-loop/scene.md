## A video background

> A .mp4 or .webm in media/ plays muted in a loop behind the scene, only while it is on screen; with reduced motion and in the self-test it stays still. The scrim keeps the text readable on it.

- scene.ts { background: { href: "media/sample.mp4", scrim: 0.5 } } — the clip covers the stage
- Keep the clip short and calm: it loops for as long as the scene is on screen

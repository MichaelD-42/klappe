## An animated background

> An aurora needs no file. It moves on the wall clock, not with the steps, and only while it is on screen; with reduced motion it stays still.

- scene.ts { background: { animate: "aurora" } } — a slow drift of light in the theme's colours
- A .mp4 or .webm href plays muted in a loop the same way: { background: { href: "media/loop.mp4", scrim: 0.6 } }

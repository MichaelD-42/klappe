## A squash merge

> HEAD marks the commit you are on and moves with checkout and with each commit on that branch; a squash lands the whole branch on main as one commit.

- The first commit on main.
- Check out main: HEAD appears.
- A feature branch from main.
- Check out the feature: HEAD moves.
- A commit on the feature; HEAD follows it.
- Another one.
- Back to main.
- Squash the feature onto main: one commit, one parent.
